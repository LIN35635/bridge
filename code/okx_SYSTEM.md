# 交易系统（用户定稿 2026-10-17）

理念：轻仓，顺势，止损。盈利单绝不变成亏损单。尽量少做，多做多错。交易是概率游戏。

## 1. 只做 BTC
- 主动交易（加杠杆）只做 BTC-USDT，不做其他币。
- 外汇、黄金、ETF、纳指、标普 500 等是定投长期资产，不走这套杠杆交易系统，两摊分开。（用户 2026-10-23 澄清：2026-10-17 晚的「多市场」更正把定投长期资产和杠杆交易混在一起，以本次澄清为准。）

## 2. 轻仓
- 单笔保证金 = 总资金的 10%，5 倍杠杆后名义 50%。
- 拿 10000 打比方：保证金 1000，名义 5000。
- 一笔亏多少算轻：亏总资金的 1% 叫轻，亏 5% 就不叫轻了。

## 3. 顺势（突破支撑 / 阻力）
- 入场不是“跌久了就做多”，是跌破 / 突破支撑阻力才做。
- 做多：价格涨超以前的阻力位 → 试着做多。
- 做空：价格跌破以前的支撑位 → 试着做空。
- 周线定方向，日线找进场：周线看大方向，日线等突破支撑 / 阻力那一下才进。
- 看不懂就不做。没波动、不确定就不做，有波动才能判断。

## 4. 止损
- 硬止损：价格逆势 2% 就止损，单笔亏 = 总资金的 1%。
- 进场就绑定止损，不扩宽、不硬扛。

## 5. 止盈（盈利单绝不变成亏损单）
- 盈利到 2%（1 倍止损）：止损移到入场价，保本，这笔最多不亏。
- 盈利到 4%（2 倍止损）：平一半，落袋一半。
- 剩下一半：用移动止损跟着走，周线翻方向了就全出。

## 6. 持仓时间
- 一笔最多拿 1 个月，到时间就出，不拿 6 个月。

## 7. 资金隔离
- 交易资金跟还款 / 生活费 100% 隔离，亏完也不影响还债。
- 不用借来的钱、不用生活费、不用还款的钱交易。

## 8. 少做
- 一年就做几笔看得懂的，不天天做。
