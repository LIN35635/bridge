# LINZHIFENG 个人中枢

这是个人网站的线上版本，采用纯静态 HTML，无需构建步骤，也不依赖外部字体或图片。

## 内容与数据

- 原有九个交互模块和六部分个人档案均保留；档案正文没有重写。
- 《天命》原始规范全文（含第四部分）已在档案中逐字附录，并提供同字节的 Markdown 原文件下载；此前整理摘要作为历史说明单独保留。
- 首页按财务、身体、目标与行动、复盘与档案重新编排，并补充公开档案摘要。
- 到账页面把真实收入、借入款、资产变现和其他流入分开统计。已有借款记录依据原类别和备注单列，不计入真实收入合计。
- 页面内的交互记录保存在当前浏览器的 `localStorage`；访客新增的记录不会自动同步给其他访客。

## 数据更新顺序

个人档案正文是公开事实来源。每次更新按这个顺序维护：

1. 先更新 `index.html` 的「完整个人档案」正文，标注日期和确认状态，并保留旧值与历史记录。
2. 再把同一项变更同步到首页摘要和对应交互模块的默认数据，核对单位、日期和统计口径。
3. 用户通过模块表单新增的内容只存在当前浏览器，不会自动写回公开档案；要公开这些变更，需先核实后手动按上述顺序整理。

页面视觉结构保持不变：档案作为数据依据，首页与模块继续按现有设计呈现。
